# Retro Pong

Green-on-black pong in one HTML page. You play the left paddle. The computer plays the right. First to 5 wins. Paddle hits and walls play square-wave blips through the Web Audio API.

Move with W / S or the up and down arrow keys.

Open `index.html` in a browser. There is no build. The game is `pong.js` on an 800×400 canvas.
